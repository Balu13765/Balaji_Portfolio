# Balaji Ganugapichi — React Portfolio

Modern responsive portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personal files

Add your profile photo as:

`public/images/profile.jpg`

Add your resume as:

`public/resume.pdf`

Then update the photo placeholder in `src/App.jsx` if desired.

## Deploy

This project uses a relative Vite base (`./`) so it can be hosted on GitHub Pages.
